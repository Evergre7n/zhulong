# 易变事实登记簿

这是空模板，没有内置事实或来源黑名单。可复制到自己的项目，并通过 --registry 指定。
来源规则 S 行的识别词用全角分号分隔，精确限定失效子体系；不要仅凭域名禁用整个网站。
事实 V 行记录现行、过时、被推翻或待核状态。价格类研究的所在 dossier 列填写完整研究目录名。
